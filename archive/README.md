# Архив секций

## bot-section.html

Секция **«Бот-помощник»** временно убрана с главной страницы, но сохранена здесь.

Чтобы вернуть на сайт:

1. Вставьте содержимое `bot-section.html` в `index.html` в нужное место (например, после CRM или приложений).
2. Добавьте пункт в меню и в блок «Решения».
3. Логика чата уже есть в `js/main.js` (`chatLog` / `chatQuick`) — заработает, если снова появятся элементы `#chatLog` и `#chatQuick`.
