# Архив секций

## bot-section.html + bot-chat.js

Секция **«Бот-помощник»** временно убрана с главной страницы.

Чтобы вернуть:

1. Вставьте содержимое `bot-section.html` в `index.html`.
2. Подключите `<script src="archive/bot-chat.js"></script>` после `js/main.js`.
3. Добавьте пункт в меню и в блок «Решения».
4. Стили `.widget` / `.msg` / `.quick` уже есть в `css/styles.css`.

## contact-form.html + contact-form.js

Форма заявки блока **«Связаться»** временно заменена на кнопки мессенджеров.

Чтобы вернуть форму:

1. В `index.html` в секции `#contact` вместо `.contact-messengers-block` вставьте разметку из `contact-form.html`.
2. Добавьте в конец `js/main.js` код из `contact-form.js` (или подключите файл).

## Демо.md

Исходный HTML-макет конструктора материалов (черновик). На работу сайта не влияет.
