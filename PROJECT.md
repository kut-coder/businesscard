# Цифровые решения для специалистов сферы здоровья

Документ контекста финального проекта курса по вайбкодингу.  
Обновлено: 4 сентября 2026.

---

## 1. Суть проекта

Сайт-визитка автора **Уториной Ксении** — специалиста по здоровому питанию, которая создаёт цифровые решения для **специалистов сферы здоровья** (нутрициологов и смежных практик), а не «для пациентов / про здоровье в общем».

Позиционирование:

> **Цифровые решения для специалистов сферы здоровья**

Ключевая мысль: автор сама из профессии, знает рутину практики и собирает сайты, веб-сервисы, CRM и мини-приложения **на языке профессии**, под контролем специалиста.

Это **не** бренд «нутрикод» (от него отказались).  
Слово «вайбкодер» в публичных текстах **не используется**.

Репозиторий на GitHub: [kut-coder/businesscard](https://github.com/kut-coder/businesscard)  
Основная ветка для публикации: **`main`**. Страховка старой версии: ветка `backup-main`.

## 4. Дизайн-система

| Токен | Значение | Роль |
|---|---|---|
| `--cream` | `#f4eee4` | фон страницы |
| `--paper` | `#fbf7f0` | карточки / поверхности |

| `--ink-soft` | `#3c3832` | вторичный текст |

| `--moss` / `--sage` | `#3a4a3c` / `#8aa084` | вторичный акцент |

Трекер привычки использует отдельную палитру (лиловый / лавандовый / мятный) внутри `.habit-app`.

### Шрифты

- Display / заголовки: **Fraunces** (serif)
- Текст UI: **Manrope** (sans)

### Паттерны UI

- Класс `.hint` — **курсив**: инструкции посетителю
- Класс `.muted` — обычные пояснения
- Кнопка `#toTop` — по центру внизу, после прокрутки
- Grain-оверлей; sticky-шапка; мобильное меню (`#menuBtn` / `#nav.open`)

## 8. Интерактивные демо (логика)

Файл: `js/main.js` (+ отдельно `vitaminki-demo/js/` для игры)

### 01 · Веб-сервис

1. **Конструктор материалов** (`#materialStudio`)  
   - Форматы: рецепт / гайд / чек-лист «Гигиена сна»  
   - Живое превью; кнопка «Загрузить свой» и скачивание JPG/PDF — **неактивны** (пример полной версии)  
   - Tip уменьшен на 3 pt (`.ms-tip`)

2. **Конструктор дня** — чипы `energy` / `cycle` / `family` → карточки приёмов. Поле «Ограничения» **убрано**.

3. **Список продуктов** (тёмный) — загрузить меню → список без дублей → демо «Скачать PDF».

### 02 · Сайты

1. Лендинг **Мария Светлова**
2. Школа **«ТАРЕЛКА»** — другая структура (шапка, split, программа, кабинет)

### 03 · CRM

Вкладки: Клиенты / Финансы / Сегодня

### 04 · Мини-приложения

1. **Витаминки** — iframe `vitaminki-demo/index.html`  
   Сокращённый сценарий: старт → детский вопрос A → факт → результат → передача взрослому → B12 → факт → переход к специалисту.  
   Кнопка «Вернуться в начало» на финале.

2. **Трекер привычки** — 21 день, кольцо прогресса, неделя из 7 дней, мотивирующие статусы по дням, «Отметить день» / «Начать заново». Цвета как в референсе (лиловый / лаванда / мята).

### Архив: бот

В `archive/bot-section.html`: кабинет «Личный кабинет» / «Меню», виджет «Помощник Ольги», ветки замены / режим / самочувствие → связь с Ольгой.  
Текст финала: *«Передала ваш запрос Ольге…»* + курсив про мессенджер.

## 9. Адаптив

Брейкпоинты в `css/styles.css`:

- **≤1100px** — уплотнение сеток  
- **≤960px** — одна колонка, мобильное меню, studio и tools в столбец  
- **≤600px** — всё в 1 колонку; hero-card под фото на узких экранах  
- **≤400px** — мельче типографика  

Навигация решений: сетка **2×2** (четыре карточки).

Для iframe «Витаминки» удобнее локальный сервер (`file://` может блокировать iframe):

```bash
python -m http.server 8765
```

## 10. Решения и ограничения по смыслу

- Позиционирование только как **помощь специалистам**, не пациентам напрямую.
- В публичных текстах не обещать контент-маркетинг как основной продукт.
- Инструкции посетителю — курсивом (`.hint`).
- Герой: фото автора за работой; плашка не должна закрывать руку (верх плашки под рукой, низ может выходить за кадр).
- Бот и отдельный экран «Стиль» не показывать в меню, пока не вернут осознанно.
