# Витаминки — демо для businesscard

Сокращённая интерактивная версия игры «Витаминки» для встраивания в сайт-визитку [businesscard](https://github.com/kut-coder/businesscard.git) вместо первого примера приложения («Завтрак-детектив»).

Полная игра в папке `Vitaminki-demo` **не изменяется** — здесь отдельная автономная копия.

---

## Что входит в демо-сценарий

| Шаг | Экран |
|-----|--------|
| 1 | Старт — «Добро пожаловать в Витаминки!», одна кнопка **«Я ребёнок»** |
| 2 | Детский вопрос — витамин A (морковка) |
| 3 | Факт про витамин A |
| 4 | Результат — «Витаминный суперсыщик» (90 баллов для показа) |
| 5 | «Передать игру взрослому» → взрослый вопрос B12 |
| 6 | Факт про B12 |
| 7 | «А как насчёт разнообразия вашего рациона?» |
| 8 | Приглашение нутрициолога — «Разобрать мой рацион» |

**Не включено** (есть в полной игре): 8 детских вопросов, заставка взрослой игры, полный взрослый квиз, выбор «Я взрослый» на старте, кнопки «Назад» и «К началу игры», реальная отправка в мессенджер.

**Особенности демо:** сценарий линейный — посетитель идёт только вперёд по шагам таблицы выше; взрослый блок открывается через «Передать игру взрослому» на экране результата.

## Установка за 3 шага

### 1. Скопируйте папку в проект businesscard

Скопируйте **`vitaminki-demo`** (из этой папки) в корень репозитория businesscard:

```
businesscard/
├── index.html
├── css/
├── js/
├── assets/
└── vitaminki-demo/          ← сюда
    ├── index.html
    ├── css/
    ├── js/
    └── assets/
```

Можно скопировать всю папку `vitaminki-businesscard-demo`, но для работы нужна только **`vitaminki-demo`**.

### 2. Замените первый телефон в `index.html`

Откройте `index.html`, найдите секцию `id="apps"`, первый блок `.phone-col` (сейчас «Завтрак-детектив»).

Замените его содержимое на фрагмент из файла:

`integration/phone-block.html`

Также обновите подпись в `.section-head` секции `#apps`, если нужно — например:

```html
<p class="muted">Два характера: игра «Витаминки» и спокойный 21-дневный ритм. Оба заканчиваются тёплым приглашением на консультацию.</p>
```

И в навигации `#services` (первая карточка):

```html
<a href="#apps"><strong>Обучающее приложение</strong><span>Мягко учит и аккуратно ведёт к консультации</span></a>
```

(Тексты уже подходят — менять необязательно.)

### 3. Добавьте стили для iframe

В конец **`css/styles.css`** businesscard вставьте содержимое файла:

`integration/businesscard-styles.css`

---

## Проверка

1. Откройте `businesscard/index.html` локально (или через `python -m http.server 8765`).
2. Прокрутите до секции «01 · приложение».
3. В первом телефоне нажмите **«Я ребёнок»** → ответьте на вопрос → пройдите до финала.

Отдельно можно открыть `vitaminki-demo/index.html` — игра работает и без визитки.

> В демо нет кнопок «Назад» / «К началу игры» и выбора «Я взрослый» на старте — только линейный сценарий для визитки.

## Удаление старого квиза из main.js 

Код «Завтрак-детектив» в `js/main.js` (`quizTexts`, `showQuiz`, обработчики `[data-next='quiz']`) после замены HTML **не мешает** — просто не используется. Удалить для чистоты.

## Настройка под себя

| Что изменить | Где |
|--------------|-----|
| Тексты вопросов и фактов | `vitaminki-demo/js/data.js` |
| Сценарий экранов | `vitaminki-demo/js/app.js` |
| Баллы на экране результата | `DEMO_CHILD_VITAMINS_SHOWCASE` в `data.js` |
| Текст финальной заглушки | `renderContactSoon()` в `app.js` |
| Персонажи / картинки | `vitaminki-demo/assets/characters/` |

---

## Важно про iframe и GitHub Pages

Пути относительные (`vitaminki-demo/index.html`) — работают при открытии с того же домена. Для GitHub Pages положите `vitaminki-demo` в корень репозитория рядом с `index.html`.

Если iframe блокируется политикой браузера при `file://`, используйте локальный сервер:

```bash
python -m http.server 8765
```
